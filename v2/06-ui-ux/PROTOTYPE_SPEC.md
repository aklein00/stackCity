# Proposed V2 interaction proof

## Aim

Show how an appealing environment helps a teen understand a financial choice. The learning question and exact numbers must be chosen before claiming a validated lesson.

## Comparable first screen in each direction

Present an investment choice with available resources, existing commitments, a consequence preview, and a clear confirm/revise action. Keep the semantic task comparable while letting the visual world differ.

## Deeper flow in one recommended direction

Target approximately 5–7 primary views plus relevant variants:

1. Persistent hub / current goal.
2. Workspace or business opportunity.
3. Inspect options and cost.
4. Compare commitment, capacity, and remaining reserve.
5. Confirm and see a consequence.
6. Outcome explanation and revision/retry.
7. Optional progression / return to hub.

These are proposed views; combine them when a clearer interaction supports the same evidence.

## Required proof

- Before/after resource values reconcile.
- Preview is distinct from committed action.
- Back/cancel preserve sensible state; actions do not double-charge.
- A changed condition or shortfall has an understandable recovery route.
- Primary action, selection, unavailable, and success states are demonstrated.
- Information is readable at intended device size.
- Keyboard/focus and reduced-motion intent are documented.
- No claim that a Figma simulation is implemented game logic.

## Components and documentation

Define tokens, hierarchy, navigation, controls, item cards, financial summaries, inspector, consequence preview, feedback, and relevant state variants. Show an alternative you rejected and explain why.

## Review

Record task, participant or reviewer, observed behavior, problem, severity, revision, and follow-up result. A self-review is not teen validation. The review template is in reviews/.
