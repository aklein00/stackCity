# Stack City V2 — art direction and UI/UX exploration

Created 2026-11-05. This is a separate exploration workspace; existing Stack City documentation, concepts, source, Figma records, and prototype remain intact.

## Selected exploration directions

1. **Sketchbook Botanicals** — expressive line, real plant structure, nursery/greenhouse spaces, journal-based UI.
2. **Wright-inspired City-States** — horizontal architecture, civic spaces, useful objects, Games preparation and comparison.
3. **Syd Mead Retro-Future** — functional object families, modular businesses, industrial design, readable resource signals.

These three exploration tracks were selected by Art. No final winning direction or production game premise has been selected.

## Working rules

- Add V2 material here. Do not overwrite V1 or reinterpret earlier approvals as V2 approvals.
- Reference boards use existing named work and photographs. No generated art belongs in the source-reference collection.
- Keep generated studies, original handmade work, blockouts, and final designs identifiable.
- LoRA training is not a current deliverable.
- UI remains native and editable in Figma; a concept screenshot alone is not UX evidence.
- This is an untimed hiring-fit case study. Milestones are quality checkpoints.
- The repo is a record of actual work: a scaffold or planned file is not a completed asset.

## Naming

Use `scv2_<direction>_<asset-or-screen>_<view-or-state>_v001.ext`.
Direction codes: `bot`, `cst`, `rtf`, `shared`.
Example: `scv2_bot_potting-room_camA_v001.png`.
Keep version history and a source/provenance record when selecting or deriving an asset.
