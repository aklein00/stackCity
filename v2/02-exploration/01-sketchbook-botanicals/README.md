# Sketchbook Botanicals

## Identity to test

Broken contours, paper, quiet washes, recognizable plant silhouettes, and an authored field-journal feeling.

## References

Schiele's Sunflowers; Kollwitz's Suburb for trees, mass and atmosphere; real RHS dahlia/cosmos photographs; Kew's Temperate House; Great Dixter's Long Border; Haws watering-can anatomy. UI precedents: Strange Horticulture and Botany Manor.

## First work

Potting-room thumbnail → greenhouse bay → nursery storefront.
Props: plants, packets, pots, watering can, snips, trays, labels.
UI: catalogue → specimen → cost/growing commitment → reserve → confirm/revise.

## Handmade proof

Gesture studies of stems and flower heads, a loose potting-room composition, a tool silhouette sheet, and a journal layout.

## Guardrails

Keep the world inviting; source melancholy does not require a gloomy game. Preserve number legibility and editable text. Keep sketch texture out of essential controls. Teen appeal is a hypothesis about collecting, ownership, and discovery.
