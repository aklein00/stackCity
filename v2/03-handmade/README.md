# Original handmade work

Preserve Art's own contribution as authored material.

- [scans](scans/README.md): untouched captures.
- [working](working/README.md): editable drawing/paintover files.
- [exports](exports/README.md): selected presentation views.

Suggested evidence: environment thumbnails, prop silhouettes, layout experiments, UI sketches, three more developed studies. Start small and let the selection process show judgment.

For each item record date, direction, purpose, medium/tool, active minutes when known, and any generated/blockout inputs used. Label mixed-media paintovers honestly. Never label generated line art as handmade.

No handmade artwork has been created by this folder setup.
