# Stack City — roadmap and decision log

## Baseline

2026-11-03. Pre-brief planning. Documentation is the only completed project artifact in this pass.

## Proposals, not approvals

New-resident narrative, landscape mobile/tablet, elevated three-quarter camera, 18-screen inventory, three-ledger economy, specific demo amounts, progression state names, first-session help rules, and prototype reward values.

## Order of work

1. Read the incoming brief and reconcile it with confirmed decisions.
2. Build Stack City's low-fidelity game flow, screens, reusable UI, and complete prototype loop in Figma.
3. Validate both budget branches, return paths, currency clarity, and reset.
4. Establish game visual direction using owner-supplied art and matched city states.
5. Produce WorldFarm's separate Figma wireframes and prototype.
6. Implement a small WorldFarm composition app when requested.
7. Use reusable environment assets to expand Stack City's presentation.

WorldFarm is not a prerequisite for game wireframes or pitch development.

## Acceptance for the first Figma milestone

Editable file and connected prototype; main loop plus adjustment/store/help branches; correct scenario arithmetic; components and named states; named asset placeholders; all screens reachable or marked as later; review notes and direct file/prototype links.

## Validation plan

Review an initial path with a teen audience when available. Check comprehension of available money versus total cash, clarity of purchase consequences, ability to recover, legibility on a smaller screen, and whether a new scenario can be understood. Formal learning claims require evidence beyond a pitch demo.

## Risks and responses

- Scope expands into city builder + life sim + driving game: keep one block and one learning loop.
- Monetization undermines education: keep paid cosmetics separate from simulated finances.
- Visually inconsistent generated art: lock camera and create a reusable blockout.
- Missing brief changes direction: keep assumptions explicit and scenes modular.
- Figma prototype mistaken for runtime: document curated branches and mocked world changes.
- WorldFarm consumes the schedule: retain game-first milestone order.

## Questions to resolve with the brief

Platform/orientation; regional currency; learning objectives by age; narrative frame; session duration; assessment; school versus consumer distribution; purchase constraints; scope of personal versus business finance.

## Review history

Append dates, changed decisions, reason, affected documents, and Figma links. Do not silently promote a proposal to a confirmed requirement.
